## Projeto GEE

O objetivo proposto pelo projeto é analisar a evolução das emissões de gases
de efeito estufa (GEE) ao longo dos anos. Essa análise foi segmentada por estado, para
identificar os setores mais poluentes e possíveis oportunidades de mitigação.

A fonte de dados utilizada está disponível no enderço https://seeg.eco.br/dados/.
